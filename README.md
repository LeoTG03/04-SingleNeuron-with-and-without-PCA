# 04-SingleNeuron-with-and-without-PCA

This project implements a binary classification model using a single artificial neuron and evaluates the impact of Principal Component Analysis (PCA) on model performance.
The objective is to compare two approaches:
  1- Training the model using all original features
  2- Training the model using reduced features obtained through PCA.
  
Requirements
------------------
Version: Python 3.x

Libraries used:
  - numpy
  - pandas
  - matplotlib
  - seaborn
  - scikit-learn
  - tensorflow
  - keras

Install dependencies:
-----------------------
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow

How to Run
------------------------------------------------
->  Option 1 — Jupyter Notebook

Open the notebook:
  04_SingleNeuron_withAndwithout_PCA.ipynb

Run all cells sequentially.

->  Option 2 — Python Script

Run:
python 04_singleneuron_withandwithout_pca.py
